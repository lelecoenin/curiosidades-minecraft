# curiosidades-minecraft
🎮 Projeto desenvolvido em HTML e CSS com o objetivo de apresentar curiosidades sobre o universo de Minecraft. O site reúne informações sobre personagens, mobs, biomas, estruturas e fatos interessantes do jogo em uma interface simples e organizada.
